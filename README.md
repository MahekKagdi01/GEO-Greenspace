# GEO-Greenspace

### GIS-Based Green-Space Optimization System for Urban Heat Analysis

GEO-Greenspace is a GIS-based web application designed to analyze urban environmental conditions and support green-space planning. The system uses geospatial data and interactive visualizations to identify areas affected by urban heat and assist in sustainable urban planning.

## Features

- Interactive GIS-based visualization
- Urban heat and environmental data visualization
- Green-space optimization
- Interactive charts and analytics
- Map-based exploration
- Support for sustainable urban planning
- Interactive and responsive web interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GIS & Geospatial Data
- Interactive Maps
- Data Visualization
